В данном репозитории представлены исходные файлы, результаты расчетов, а также вспомогательные скрипты для ВКР Давиденко Юлии (Университет ИТМО, НОЦ Инфохимии, 18.03.01 Химическая технология, год выпуска 2026)

**"ТопологияЛигандов.ipynb"** - скрипт подготовки файлов топологий лигандов для интерактивного докинга. Принцип работы описан в тексте ВКР.

В папке **Докинг** можно найти:
      - директорию **All_PDBs**, в которой находятся все PDB-файлы используемых комплексов, так и отдельно файлы лигандов и белков;
      - директорию **DockIt** с входными файлами для интерактивного докинга;
      - директорию **AutoDock&Vina** с входными файлами для автоматизированного докинга.

В папке **Итоговые_конформации** по папкам рассортированы итоговые конформации, достигнутые для каждого комплекса каждым из трез методов докинга. Помимо этого, в папках находятся zip файлы с входными файлами для молекулярной динамики и скриптом для последующего расчета энергий MM-GBSA.
